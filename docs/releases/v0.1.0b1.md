# MemoryGraph 0.1.0b1

**Status:** Public Beta prerelease
**Release date:** 2026-08-28

## Highlights

- One-command Codex onboarding with `memorygraph onboard-codex --project .`.
- Project-relative SQLite initialization and idempotent bank selection.
- Project-scoped MCP configuration with write approvals and fail-open host behavior.
- A real configured MCP probe covering initialize, the five-tool surface, record, recall, and
  forget, with stage-specific recovery diagnostics.
- Dogfood Beta live instrumentation and the reproducible `make dogfood-beta` accelerated gate.
- Evidence-backed temporal claims, hybrid retrieval, durable Dream workers, privacy deletion,
  Obsidian review projection, and approved Codex session ingestion from the Alpha foundation.

## Install from the GitHub prerelease

Install the published wheel directly from the GitHub prerelease:

```bash
python -m pip install https://github.com/xbrxr03/memorygraph/releases/download/v0.1.0b1/memorygraph_agent-0.1.0b1-py3-none-any.whl
memorygraph onboard-codex --project /path/to/trusted/repository
```

MemoryGraph is not yet published to PyPI. A future PyPI release will use:

```bash
pipx install memorygraph-agent==0.1.0b1
```

## Honest scope

This Beta demonstrates deterministic and locally reproduced multi-session evidence. It does not
claim production stability, five sustained external users, or a completed live Graphify
head-to-head comparison.

## Upgrade and rollback

The Beta uses the existing migration-safe SQLite schema. Back up `.memorygraph/memory.db` before
upgrading important repositories. To stop using the integration, remove only the
`[mcp_servers.memorygraph]` table from `.codex/config.toml`; the local database remains intact.
